## 기준 소스와 방법

대상 저장소는 `codewhite7777/codyssey_B2-1`이다. 전체 소스가 들어간 검증 커밋은 `3be47ef18954d0a3f34793f67758161a5ac34c73`, 트리는 `b9b54ab6329ebd65d2638f67deab73dd449d24ad`다.

GitHub API에서 위 원격 트리를 읽어 28개 파일의 Git blob SHA를 검증본과 대조했고 모두 일치했다. 이 중 Python 파일은 애플리케이션 10개, 테스트 9개, 도구 5개로 총 24개다. 원격 트리에 있는 파일만 새 폴더에 재구성하고 다시 실행했다.

실행 환경의 DNS 제한으로 직접 `git clone`은 실패했다. 따라서 다운로드 클론을 테스트했다고 보고하지 않는다. 위 검증은 GitHub API 조회 + 바이트의 Git blob SHA 일치 확인 + 원격 트리와 동일한 별도 스냅샷 재실행이다. 문서 변경 커밋은 이 소스 커밋과 구분한다.

## 실패 상황과 미검증 범위

write/fsync/replace/temp 생성 실패, 잘못된 CSV, 손상 JSONL, 잘못된 인코딩, 중복 ID, 사용 중 카테고리, 잠금 충돌, 출력 파이프 종료를 검증했다. 파일 오류 일부는 예외 주입으로 재현했으며 실제 저장장치 공간 소진·전원 차단 실험은 아니다.

Python 3.10 실제 인터프리터, macOS/Windows 실제 실행, 정전 내구성, 외부 편집기 동시 수정, 자동 백업·복구는 미검증 또는 미구현이다. 타입 힌트 검토와 AST 검사를 수행했지만 외부 정적 타입 검사기는 실행하지 않았다. GitHub Actions 실행 결과도 아니다.

## 완료 상태 해석

원격 소스 커밋 생성, 기본 브랜치 반영, 테스트 통과, 사용자의 학습·피어 평가는 서로 다른 단계다. 이 문서는 위 커밋의 실제 테스트 근거이며, 제출 여부나 피어 평가 합격을 보장하지 않는다. 최종 응답의 main 커밋 확인 결과와 함께 판단한다.
